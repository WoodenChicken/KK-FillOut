真实语料保存后参与下一次训练。合成语料由规则生成，可复制为真实语料后修改。

如何准备和管理训练语料？

文本填写网页上的字段标签，例如「教育经历 毕业院校」；类别选择「教育经历 / 学校」。不要填写个人简历的具体值。

可导入扩展侧栏「设置 → 导出样本」生成的 JSONL，或每行一个对象：{"text":"教育经历 毕业院校","label":"education.school"}。

新增、编辑和删除自动保存到 ml/train/fillout-samples.jsonl。导入会跳过相同文本和类别的重复记录；如有错误行，整批不保存。导出包含全部真实语料，不受筛选影响。

合成语料的数量受「参数调优」中的随机种子和每 pattern 样本数影响。字段文本须为 2～200 个字符，以符合训练清洗规则。训练期间可浏览和导出，修改操作在训练结束后恢复。
